Engineering Excellence & Features

Modular, high-performance architecture built for precision desktop automation.

📐

Continuous 3D Euclidean Math

Continuous spatial distance calculation between arbitrary node pairs (e.g. Node 4 and Node 8) with automatic hand-scale normalization and hysteresis state flags.

🎯

Context-Aware Routing

Automatic foreground window inspection using pygetwindow. Routes gestures into specialized hotkeys for Adobe Premiere Pro, Figma, Browsers, and Media.

🛠️

Developer Workbench

Interactive calibration suite with click-to-select canvas nodes, real-time threshold sliders, synthetic data runner (test without camera), and live JSON export.

⚡

Dual Macro Engine

Instantaneous system-level hotkey dispatch through the low-level keyboard library combined with pyautogui for smooth cursor clicks and drags.

🛡️

Two-Stage MediaPipe ML

Stage 1 BlazePalm detector isolates hand bounding box and ignores background clutter and faces; Stage 2 extracts all 21 3D spatial joint coordinates.

📦

Standalone Executable

Packaged into a single standalone Windows .exe with bundled pre-trained models and dependencies—no Python installation required.
